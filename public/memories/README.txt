Put your photos and videos in this folder.

Names to use (any of .jpg, .png, .webp or .mp4):
  cube-1 ... cube-6        the six faces of the 3D cube
  memory-01 ... memory-20  the "Our memories" frames
  reel-1 ... reel-4        short clips
  closing                  the final picture

Example: memory-01.jpg, reel-2.mp4, closing.webp

The cube photos, memory frames and reel clips are shuffled into a new
order every time the page loads.
If a file is missing, the site shows a soft placeholder tile instead.

Optional: a still picture shown before a video loads. Name it like the
video with "-poster" added, e.g. reel-1-poster.jpg for reel-1.mp4.
